# Elsewhere — Prishtina
take a look : https://elsewhere-prishtina.netlify.app/

Elsewhere is a city guide for discovering places and planning things to do in Prishtina, Kosovo. Browse local cafés, restaurants, landmarks, parks, libraries, mosques, the cathedral, and shopping and entertainment malls, then save places to a personal plan.

## Stack

- React 18
- JavaScript (ES modules)
- Vite 6
- Lucide React icons
- CSS

## Getting started

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
